# ReporTek®

**Real Data. Real Insights.**

ReporTek® is a standalone Windows reporting application developed and owned by EraZer0 Corp.

## Windows Download

Official Windows installers are distributed through this repository's **Releases** page.

ReporTek uses offline product licensing. After installation, ReporTek displays an Installation ID. After purchasing a license, provide that Installation ID to EraZer0 Corp. to receive the signed ReporTek license key for that installation.

License verification is performed locally. ReporTek does not require a connection to an EraZer0 Corp. licensing server or the seller's computer.

## Tekmetric Connection

ReporTek connects directly to the customer's authorized Tekmetric API account to download and index reporting data.
